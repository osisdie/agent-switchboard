# Diagram sources

The README diagrams in `docs/assets/*.svg` are generated by these scripts (Python 3 stdlib only, no
external fonts or libraries). Edit the scripts, not the SVGs.

| Script | Output |
|---|---|
| `gen_lifecycle.py` | `docs/assets/lifecycle-gates-light.svg`, `lifecycle-gates-dark.svg` |
| `gen_arch.py` | `docs/assets/architecture-light.svg`, `architecture-dark.svg` |
| `gen_common.py` | shared helpers: light/dark palettes, extruded cards, chips, gate pills, arrow markers |

Regenerate from the repo root:

```bash
python3 docs/assets/src/gen_lifecycle.py
python3 docs/assets/src/gen_arch.py
```

Each script writes to `docs/assets/` by default; pass a directory as the first argument to write
elsewhere. Afterwards, check both themes in a browser at about 900 px and 1600 px wide, so that no
text overflows a card.
