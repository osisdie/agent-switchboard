        Switching accounts 切換帳號

        The operator is a Claude session, so it stops when its account reaches the 5-hour or weekly limit. Alerts keep going out without it.

        1. At 90% in either window, finish or park long tasks and pick a backup account that can edit this board.
        2. In a Claude Code session on that account, run the operator prompt (prompts/board-operator.md) with this board's link. It takes over the heartbeat.
        3. When the original operator comes back and sees a fresher heartbeat from another session, it stays passive.
        4. Answers given here while nobody operates the board are saved and relayed by the next operator, oldest first.
        80% · heads-up90% · prepare to switch95% or limit hit · switch now

        How this works 運作方式

        1. HooksEach session's hook writes a small state file on every event: working, needs you, done or offline.
        2. CollectorMerges the state files with the live session list and tmux into one snapshot.
        3. OperatorA dedicated session syncs that snapshot to this board and keeps a heartbeat.
        4. BoardYou answer decisions and write messages here. Answers are saved to the board's data.
        5. RelayThe operator picks up answers and messages, presses the prompt or messages the session, and posts replies back.
