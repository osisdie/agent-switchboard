On this page

    Start here

    The board's public API (/api/v1) and its MCP server (/mcp), for scripts, services and MCP clients. Everything below is generated from this board's live route table.

    1. Get an API key on API keys. It is shown once: keep it in an environment variable (BOARD_API_KEY), never in a file you commit.
    2. This board is reached through Cloudflare Access: a client also needs an Access service token (CF_ACCESS_CLIENT_ID, CF_ACCESS_CLIENT_SECRET) listed in serve.tunnel.api_service_tokens, from the board's owner.
    3. Connect a client (below), then run the health check.

    A key reads what a board viewer sees and never decides: no route or tool answers a decision, presses a prompt or manages keys.

    Troubleshooting

    Errors are JSON: {"error": "<code>", "detail": "…"}. Over MCP, an access error is JSON-RPC error -32001 naming the same code; a route's own refusal is a tool result with isError: true.
